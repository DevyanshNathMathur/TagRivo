03 / READ BEFORE SHARING

There are limits
to a clean scan.

What does a zero risk score mean?

Only that no risk was identified by the supported metadata checks. It does not prove anonymity, overall privacy or file safety.

What might still identify someone?

Visible faces, names, addresses, document text and other information in the file itself can remain even after metadata sanitization.

What changes when a PDF is sanitized?

PDF pages may be rebuilt as images. Searchable text, hyperlinks, forms, digital signatures and accessibility features may be lost. Compare the copy with the original before using it.
